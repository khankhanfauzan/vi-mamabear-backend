Backend REST API untuk **MamaBear**, platform e-commerce produk ibu dan bayi.
Dibangun dengan [NestJS](https://nestjs.com/) + TypeScript, PostgreSQL (dengan
[pgvector](https://github.com/pgvector/pgvector) untuk pencarian semantik produk),
Prisma ORM, dan fitur **AI Health Assistant** berbasis OpenRouter dengan guardrail medis.

Fitur utama: katalog produk & varian, cart, order, pembayaran (Midtrans), pengiriman
(RajaOngkir), review, customer, alamat, upload gambar (Cloudinary), notifikasi email
(SMTP/Brevo/MailHog), laporan, activity log, dan chat AI untuk pertanyaan kesehatan
ibu & bayi.

## Setup & Pengembangan

Panduan lengkap menyiapkan environment lokal (dependensi, environment variables, database pgvector, migrasi, seed), menjalankan server, testing, dan Docker ada di halaman terpisah:

- **[Setup Backend di Lokal](/docs/developer/backend/setup-lokal)** — dari clone sampai server berjalan

Ringkasan cepat:

```bash
git clone git@github.com:khankhanfauzan/vi-mamabear-backend.git
cd vi-mamabear-backend
npm install
cp .env.example .env          # isi DATABASE_URL & JWT secrets
docker compose up -d db mailhog
npx prisma migrate deploy
npm run start:dev             # server di http://localhost:3001
```

## API & Kode Style

- Daftar endpoint lengkap: [Standar & Referensi API](/docs/developer/backend/api-reference). Koleksi request siap pakai ada di folder `bruno/` (Bruno API client).
